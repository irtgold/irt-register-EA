# IRT Gold Co-Pilot — ลิงก์สำหรับส่งลูกค้า

ทุกลิงก์เปิดได้เลยทั้งมือถือและคอม ไม่ต้องล็อกอิน · กดปุ่มคัดลอกที่มุมขวาของกล่องได้เลย

## 1. หน้าลงทะเบียนรับ EA

```
https://irtgold.github.io/irt-register-EA/
```

ลูกค้ากรอก: ชื่อ-นามสกุล · เบอร์โทร · XCELLA ID · อีเมล · เลขพอร์ต MT5 · จำนวนเงินในพอร์ต
ในหน้ามีขนาดพอร์ตให้เลือก 3 ระดับ พร้อมเป้าหมายและความเสี่ยง · ข้อมูลเข้าระบบหลังบ้าน → ทีมงานกดอนุมัติ → ลูกค้าได้ไฟล์ EA + License Key ทางอีเมล

## 2. คู่มือสมัครบัญชีเทรด XCELLA PRIME

```
https://irtgold.github.io/irt-register-EA/signup.html
```

9 ขั้นตอนพร้อมภาพจริงจากมือถือ: สมัคร → ยืนยันอีเมล → ล็อกอิน + รหัส 6 หลัก → ยอมรับเงื่อนไข → ยืนยันตัวตน (KYC) → ฝากเงิน → เปิดบัญชี CENT-X → รับเลขพอร์ต → โอนเงินเข้าพอร์ต

## 3. คู่มือเช่า VPS

```
https://irtgold.github.io/irt-register-EA/vps.html
```

8 ขั้นตอน: สมัคร → เข้าสู่ระบบ → เลือกแพ็กเกจ P1 (200 บาท/เดือน) → เลือกรอบชำระเงิน → ตะกร้า → จ่ายผ่านพร้อมเพย์ → รอเครื่อง 1-10 นาที → ส่ง IP/Username/Password ให้ทีมงาน

## 4. รายงานผล IRT Gold Lab V.2.0 (เปิดดูอย่างเดียว ใส่ใน LINE@ ได้)

```
https://irtgold.github.io/irt-register-EA/lab.html
```

หน้าเดียวจบ พื้นขาว ไม่ต้องล็อกอิน: การ์ด EA · พอร์ตลูกค้าจริง 3 พอร์ต (ซ่อนชื่อ/เลขพอร์ต) · ดูพอร์ตวันนี้ · Backtest · ปุ่มเชื่อมต่อ → ลิงก์สมัคร/ลงทะเบียน/LINE · เปิดแท็บพอร์ตตรง ๆ ด้วย `lab.html#ports`
